🧩 Creative Count Rules▲

One creative template = One count

A single creative concept/template is counted as 1 creative, regardless of revisions.

Revisions do not create additional counts

  • End card changes
  • CTA updates
  • Language localization or translation
  • Text modifications
  • Asset replacements
  • Status-based revisions or adjustments

Horizontal and Vertical versions count as one

Format adjustments alone do not qualify as a new creative count.

New count criteria

A new count should only be created when there is a substantially different creative concept, template, structure, or visual direction.
